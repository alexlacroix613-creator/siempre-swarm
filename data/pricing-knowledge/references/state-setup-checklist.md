# State Setup Checklist: New Market Pricing

## Step 1: Market Identification

- **State**: Identify the state (e.g., WI, KY).
- **Type**: Determine if it's a Control State or a Three-Tier State (e.g., KY is three-tier).
- **Distributor**: Verify distributor assignments and contact information.

## Step 2: SKU Selection

- **Core SKUs**: Plata, Repo, Añejo.
- **Ultra-Premium**: Supremo (if active in the market).
- **Value**: Chismé.
- **LTOs**: Exclusivo (if applicable).

## Step 3: Pricing Calculation

- **FOB**: Use standard FOB from Master Pricing Model.
- **Taxes/Freight**: Calculate state-specific excise taxes and inland freight.
- **Margin Floor**: Ensure Siempre margin is at least 30%.
- **SRP Targets**: Align with locked SRP targets (Plata 5-50, Repo 5, Añejo 0-95, Supremo 9-80, Chismé ~7 USD / ~0 CAD).

## Step 4: Documentation

- **Template**: Copy from existing state template if available, else build from Master data.
- **Status**: Set default posting_status to "pending".
- **Notes**: Document any market-specific rules or distributor requirements.

## Step 5: Submission

- **Lead Time**: Ensure 60-day lead time for any FOB changes.
- **Email**: Submit to pricing@prestigebevgroup.com after team approval.
