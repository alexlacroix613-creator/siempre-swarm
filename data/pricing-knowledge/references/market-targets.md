## Scoring Methodology

**A Markets (5-factor):**

| Factor | GREEN | YELLOW | RED |
|--------|-------|--------|-----|
| % to Target | >= 95% | >= 85% | < 85% |
| Reorder Rate (90d) | >= 50% | >= 40% | < 40% |
| Pipeline Coverage | >= 3.0x | >= 2.0x | < 2.0x |
| Core SKU Mix | >= 80% | >= 70% | < 70% |
| Spend per Case | <= $15 | <= $20 | > $20 |

Score: count GREEN factors. >=5 = GREEN, >=3 = YELLOW, else RED.

**B Markets (3-factor):** % to Target, Reorder Rate, Pipeline Coverage only. >=3 = GREEN, >=2 = YELLOW, else RED.

**C Markets (1-factor + alert):** % to Target only. >=95% = GREEN, >=70% = YELLOW, else RED. ALERT if depletions = 0 but prior month had activity.
